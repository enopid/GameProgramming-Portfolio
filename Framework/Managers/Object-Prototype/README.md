# Object and Prototype Manager

Prototype 복제와 Level·Layer 단위 오브젝트 보관을 관리합니다.

## 포함 파일

| 구현 단위 | 헤더 | 구현 |
|---|---|---|
| `Object_Manager` | `Include/Object_Manager.h` | `Source/Object_Manager.cpp` |
| `Prototype_Manager` | `Include/Prototype_Manager.h` | `Source/Prototype_Manager.cpp` |

> 전체 프로젝트의 빌드 의존성은 포함하지 않았으며, 구현 흐름을 확인하는 데 필요한 범위까지만 선별했습니다.
