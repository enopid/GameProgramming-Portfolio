# PBR Rendering

Cook–Torrance BRDF 직접광과 Split-Sum IBL을 구성하는 셰이더입니다.

## 포함 파일

| 파일 | 구분 |
|---|---|
| `Shaders/Shader_Deferred.hlsl` | Shader |
| `Shaders/Shader_Defines.hlsli` | Shader Include |
| `Shaders/Shader_PBR.hlsli` | Shader Include |
| `Shaders/Shader_ScreenSpace.hlsl` | Shader |

> 전체 프로젝트의 빌드 의존성은 포함하지 않았으며, 구현 흐름을 확인하는 데 필요한 범위까지만 선별했습니다.
