# Terrain Tool

높이 편집 브러시와 PBR Splat Map 페인팅에 사용한 코드와 셰이더입니다.

## 포함 파일

| 파일 | 구분 |
|---|---|
| `Include/TerrainRenderer.h` | Header |
| `Include/VIBuffer_Terrain.h` | Header |
| `Shaders/Shader_PBR.hlsli` | Shader Include |
| `Shaders/Shader_Terrain.hlsl` | Shader |
| `Source/TerrainRenderer.cpp` | Source |
| `Source/VIBuffer_Terrain.cpp` | Source |

> 전체 프로젝트의 빌드 의존성은 포함하지 않았으며, 구현 흐름을 확인하는 데 필요한 범위까지만 선별했습니다.
